## About This Course

This repo tracks my progress through **[Complete Agentic AI Bootcamp with LangGraph and LangChain](https://www.udemy.com/course/complete-agentic-ai-bootcamp-with-langgraph-and-langchain/)** by Krish Naik on Udemy.

The course covers how to design and build autonomous AI agents and multi-agent systems using LangGraph and LangChain. It starts with Python and Pydantic fundamentals, then moves into core LangChain concepts (document loaders, text splitters, embeddings, vector stores), and builds up to agent-specific topics: agent state and memory, tool use, event-driven workflows, multi-agent collaboration, and human-in-the-loop middleware. The course is heavily project-based, with hands-on builds like RAG agents, research assistants, and task automation bots.

**Topics covered:**
- Python & OOP fundamentals, Pydantic for data validation
- LangChain core: prompts, chains, retrievers, embeddings, vector stores (FAISS, Chroma)
- LangGraph: agent state, event-driven workflows, graph-based orchestration
- Multi-agent systems and agent-to-agent communication
- Middleware: summarization, human-in-the-loop approval
- End-to-end projects: RAG agents, autonomous research agents, task automation systems

**Instructor:** Krish Naik (KRISHAI Technologies)
**Length:** 27 sections, 183 lectures, ~45.5 hours
